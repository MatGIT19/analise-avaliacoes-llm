# Dados

Os arquivos do dataset não ficam no repositório (são grandes e têm licença própria). Para rodar o projeto:

1. Acesse [Brazilian E-Commerce Public Dataset by Olist](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce) e clique em **Download** (precisa de conta gratuita no Kaggle).
2. Descompacte e coloque nesta pasta pelo menos estes arquivos:
   - `olist_order_reviews_dataset.csv`: nota de 1 a 5 e comentário de cada avaliação
   - `olist_orders_dataset.csv`: status e datas de compra e entrega de cada pedido
   - `olist_customers_dataset.csv`: estado e cidade de cada cliente
